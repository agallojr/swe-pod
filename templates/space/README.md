# <project>-space

Project Space for `proj:<project>`: <one sentence on what the project builds>.
Specs, plans, ledgers, reviews, evidence and project-level tests live here.
The deliverables live in the code repos `pod.yaml` names.

Start with `AGENTS.md`, then `STATUS.md`.

## Layout

```
space.yaml           memory-space manifest (kind: project, shareable profile)
pod.yaml             code repos, pins, merge order, gates
PROCESS.md           the process, pinned by version in pod.yaml
AGENTS.md            read order and standing rules
STATUS.md            generated by the swe-pod skill, never edited by hand
tests/               regression suite: tests of integrated specs
changes/<id>/        one folder per change: spec, plan, ledger, tasks/,
                     tests/, evidence/, report
changes/archive/     integrated changes, as <yyyy-mm-dd>-<id>/
decisions/           <YYYYMMDDTHHMMZ>-<slug>.md, one file per decision
handoffs/            <YYYYMMDDTHHMMZ>-<change id>.md, one file per handoff
notes/  lore/        notes and verified gotchas
```

`PROCESS.md` §12 covers the Project Space.
